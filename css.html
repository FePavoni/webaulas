Fundamentos do CSS

Use esta página como uma consulta rápida durante seus estudos e projetos.

1. Estrutura básica

O CSS utiliza um seletor, uma propriedade e um valor para definir estilos.

p {
  color: white;
}

2. Seletores

Os seletores indicam quais elementos HTML receberão determinado estilo.

p {
  color: white;
}

.card {
  background-color: black;
}

#titulo {
  font-size: 30px;
}

3. Cores

O CSS permite definir cores usando nomes, códigos hexadecimais e outras formas.

color: white;
color: #ffffff;
color: rgb(255, 255, 255);

4. Background-color

Define a cor de fundo de um elemento.

body {
  background-color: black;
}

5. Color

Define a cor do texto de um elemento.

p {
  color: white;
}

6. Font-size

Define o tamanho do texto.

h1 {
  font-size: 40px;
}

7. Font-family

Define a fonte utilizada no texto.

body {
  font-family: Arial, sans-serif;
}

8. Text-align

Define o alinhamento horizontal do texto.

h1 {
  text-align: center;
}

9. Width e Height

Definem a largura e a altura de um elemento.

.card {
  width: 300px;
  height: 200px;
}

10. Margin

Define o espaço externo ao redor de um elemento.

.card {
  margin: 20px;
}

11. Padding

Define o espaço interno entre o conteúdo e a borda do elemento.

.card {
  padding: 20px;
}

12. Border

Adiciona uma borda ao redor de um elemento.

.card {
  border: 1px solid white;
}

13. Border-radius

Arredonda os cantos de um elemento.

.card {
  border-radius: 10px;
}

14. Box-sizing

Define como o tamanho total de um elemento deve ser calculado.

* {
  box-sizing: border-box;
}

15. Display

Define como um elemento será exibido e como ele ocupará espaço na página.

.card {
  display: block;
}

16. Display flex

O display flex facilita o alinhamento e a organização dos elementos dentro de um container.

.container {
  display: flex;
}
