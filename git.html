Git

Consulte os principais comandos do Git e entenda para que cada um deles serve.

Comandos essenciais

Use esta página como uma consulta rápida durante seus estudos e projetos.

1. Configurar seu nome

Define o nome que será associado aos seus commits no Git.

git config --global user.name "Seu Nome"

2. Configurar seu e-mail

Define o e-mail que será associado aos seus commits.

git config --global user.email "seu@email.com"

3. Criar um repositório

Inicia um novo repositório Git dentro da pasta atual.

git init

4. Adicionar arquivos

Adiciona os arquivos para serem incluídos no próximo commit.

git add .

5. Criar um commit

Registra as alterações adicionadas no histórico do projeto.

git commit -m "Primeiro commit"

6. Conectar ao GitHub

Conecta o repositório local ao repositório criado no GitHub.

git remote add origin URL_DO_REPOSITORIO

7. Definir a branch principal

Define a branch principal do projeto como main.

git branch -M master

8. Enviar para o GitHub

Envia os commits do seu computador para o repositório remoto.

git push -u origin master

OBS:

main também é um nome comum para a branch principal. O nome utilizado pode variar conforme o projeto.
