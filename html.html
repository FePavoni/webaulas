Consulte os principais conceitos do HTML, do básico até formulários.

Fundamentos do HTML

Use esta página como uma consulta rápida durante seus estudos e projetos.

1. Estrutura básica

Todo documento HTML começa com uma estrutura básica que organiza a página.

<!DOCTYPE html>
<html>
  <head>
  </head>
  <body>
  </body>
</html>

2. Títulos

Os títulos organizam o conteúdo da página. Eles vão de h1 até h6.

<h1>Título principal</h1>

3. Parágrafos

O elemento p é utilizado para escrever textos e parágrafos.

<p>Olá, mundo!</p>

4. Links

O elemento a cria links para outras páginas ou endereços.

<a href="https://exemplo.com">Acessar</a>

5. Imagens

O elemento img permite adicionar imagens à página.

<img src="imagem.jpg" alt="Descrição da imagem">

6. Listas

As listas podem ser ordenadas ou não ordenadas.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

7. Div

A div é utilizada para criar blocos e organizar elementos da página.

<div>
  <p>Meu conteúdo</p>
</div>

8. Classes e IDs

Classes e IDs permitem identificar elementos para estilização e manipulação.

<div class="card" id="principal">
  Conteúdo
</div>

9. Formulário

O elemento form é utilizado para criar formulários e receber informações do usuário.

<form>
  <label>Nome:</label>
  <input type="text">
  <button>Enviar</button>
</form>

10. Input

O input permite que o usuário insira diferentes tipos de informação.

<input type="text" placeholder="Digite seu nome">

11. Label

O label identifica o campo que o usuário deve preencher.

<label>Nome</label>

12. Textarea

O textarea permite que o usuário escreva textos maiores.

<textarea></textarea>

13. Button

O button cria um botão que pode ser utilizado para ações dentro da página.

<button>Enviar</button>
